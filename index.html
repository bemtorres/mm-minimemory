Arquitectura Modular del Sistema

Flujo desacoplado desde el frontend interactivo hasta la inferencia con DeepSeek y el extractor de memoria.

1. Capa UI / Cliente

Material You & Streaming

Chat multihilo, renderizado Markdown en tiempo real, gestión de sesiones y cambio de tema claro/oscuro.

2. Servidor & Rutas

Flask Server & API REST

Autenticación de sesiones, CRUD de agentes, upload de avatares y endpoints de streaming hacia la IA.

3. Compilador de Prompts

Prompt & Role Engine

Combina perfil del personaje + bases temáticas vinculadas + hechos de memoria activa + historial de diálogo.

4. DeepSeek & Memoria

Inferencia & SQLite

Inferencia con DeepSeek Chat, extracción de nuevos hechos y persistencia atómica en `agentes.db`.

Instalación Local

Comienza a Desarrollar en 3 Minutos

Ver en GitHub

1. Clonar el repositorio y configurar entorno:

git clone https://github.com/bemtorres/agente_deepseek.git && cd agente_deepseek

2. Instalar dependencias de Python:

pip install -r requirements.txt

3. Configurar API Key de DeepSeek en `.env` y correr el servidor:

cp .env.example .env && python app.py
Servidor local disponible en: http://localhost:5000 Credenciales por defecto: admin / admin123
